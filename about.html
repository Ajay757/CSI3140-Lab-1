About the Event

The uOttawa Game Dev Showcase 2026 is a fictional student event focused on introducing students to modern game development tools, design techniques, and collaborative development practices.

Students attending the event will participate in workshops, explore beginner-friendly game engines, and showcase small creative projects built during the event.

What Participants Will Learn

  1. Introduction to Unity and 2D game development.
  2. Basic gameplay programming concepts.
  3. Level design and user experience principles.
  4. Team collaboration and project presentation skills.

Featured Workshop

Hands-On 2D Game Development

The featured workshop introduces participants to creating interactive 2D games using beginner-friendly development tools and design practices.

Students will explore basic gameplay mechanics, level design, playtesting, and teamwork.
